# Project-Corporate-Backbone-Edge-LAN-Architecture
Repositori ini berisi simulasi jaringan "Corporate Backbone &amp; Edge LAN Architecture" menggunakan Cisco Packet Tracer. Proyek ini mencakup desain WAN redundan dengan topologi ring, segmentasi akses LAN, integrasi server terpusat, serta ekosistem jaringan hybrid (kabel dan nirkabel) untuk skala enterprise.

Deskripsi 
Proyek ini merupakan simulasi arsitektur jaringan Corporate Backbone & Edge LAN Architecture yang dirancang untuk kebutuhan infrastruktur multi-site enterprise. Simulasi ini dibangun menggunakan Cisco Packet Tracer untuk mendemonstrasikan integrasi yang andal antara jaringan inti terpusat dan jaringan akses area lokal.

Fitur Utama Arsitektur
1. Redundansi WAN (Backbone Layer): Memanfaatkan 4 router utama yang saling terhubung membentuk topologi ring melalui koneksi serial untuk memastikan fault tolerance dan High Availability.
2. Segmentasi Edge LAN (Access Layer): Menggunakan serangkaian switch untuk mendistribusikan dan mengelola lalu lintas data secara efisien ke berbagai perangkat pengguna akhir (end-user).
3. Infrastruktur Jaringan Hybrid: Mengintegrasikan konektivitas kabel untuk stabilitas (PC dan Server) serta konektivitas nirkabel melalui Access Point untuk mobilitas perangkat (Smartphone).
4. Pusat Layanan Terintegrasi: Dilengkapi dengan dedicated server pada area lokal untuk simulasi penyediaan layanan intranet perusahaan.

Komponen Topologi
1. Perangkat Routing (Core): 4 Unit Router Cisco.
2. Perangkat Switching (Edge): 4 Unit Switch Cisco.
3. Perangkat Jaringan Nirkabel: 1 Unit Access Point-PT-N.
4. Perangkat Akhir (End Devices): 11 Unit PC, 2 Unit Smartphone, dan 1 Unit Server.
